# ⚡ Number Surge

> A fast-paced, arcade-style browser math game. Click floating bubbles to solve equations before time runs out!

## 🎮 Features

- **5 Game Modes:**
  - ➕ **Addition:** `_ + _ = Target`
  - ➖ **Subtraction:** `_ − _ = Target`
  - ✖️ **Multiplication:** `_ × _ = Target`
  - ➗ **Division:** `_ ÷ _ = Target`
  - 🔀 **Mixed Mode:** Dynamic questions rotating across all operations
- **⚡ Speed Bonus System:** The quicker you identify and click the right pair, the more extra points you score (up to +20 bonus per question).
- **🔥 Combo Multiplier:** Consecutive correct answers build your combo multiplier for massive scores.
- **📈 Progressive Difficulty:** Speeds up and introduces wider number ranges as you solve more questions.
- **🔊 Web Audio API:** Fully synthesized, zero-asset audio effects with an instant mute toggle.
- **📱 Fully Responsive:** Optimized for both mouse and mobile touch controls.

---

## 🚀 How to Play

1. Open `index.html` in any modern web browser.
2. Select your desired game mode (Addition, Subtraction, Multiplication, Division, or Mixed).
3. Click **Start Game** (60 seconds on the clock).
4. Click two floating number bubbles that satisfy the target equation displayed in the top bar.
5. Solve as many equations as you can before time expires!

- **HTML5** — Semantic, accessible structure

- **Vanilla JavaScript** — `requestAnimationFrame` loop, Web Audio API, modular state management
